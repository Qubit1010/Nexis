# Quetta Local Market

Go-to-market for NexusPoint in Quetta: fresh sector research, a named prospect database, a
competitor teardown, and a bilingual (English + Urdu) sales kit in the official NexusPoint brand.

Started 2026-09-30. Supersedes the 2026-09-28 kit, which is archived at
`archives/quetta-kit-2026-09-28/` and was deliberately not used as input.

## Layout

| Folder | What | Tracked |
|---|---|---|
| `research/` | Raw research notes and source captures | No |
| `data/` | Prospect scrape, scoring, kit data (sectors, tiers, proof) | No |
| `templates/` | HTML templates + `brand.css` | Yes |
| `scripts/` | Build, scrape and QA scripts | Yes |
| `build/` | Intermediate renders | No |
| `deliverables/` | Final PDFs, deck, xlsx | No |

Prospect data and pricing never go in git. Finals are backed up to the Drive folder
"NexusPoint - Quetta Market Kit".
