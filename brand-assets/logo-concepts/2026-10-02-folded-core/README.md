# NexusPoint, Folded Core variations

Four variations of the user's preferred logo image, ChatGPT Image Oct 2, 2026, 03_07_09 AM.png. A copy is preserved as preferred-reference.png.

- 01 Precision Fold: closest refinement, clean diagonal seams and balanced geometry.
- 02 Open Core: recommended starting point, slimmer panels and a wider opening around the point.
- 03 Sculpted Ribbon: softer transitions and rounded shoulders.
- 04 Offset Fold: staggered terminals and unequal fold proportions.

The source's tight inward curl, readable N and one central dot are kept. All images use white shapes on black and target portfolio blue #02A1E1. These are exploratory raster concepts. Exact colour and refined construction are to be enforced in the chosen production vector.

Method: built-in imagegen edits using the supplied reference, with opaque output to keep edges clean. prompts.json contains the exact prompt set. Individual source symbol PNGs are unchanged; native CSS composition presents symbols at equal visible height, with the agency's existing outlined wordmark. The comparison headings use the copied portfolio Conthrax font.

logo-comparison.png contains the complete comparison. Each *-lockup.png contains one full logo preview. The PNG package contains images, prompts and this README, with no font binaries. HTML and the build script depend on the existing brand-kit assets and fonts and are for local preview.

The existing approved master and banners are preserved. No agency-wide identity replacement has been made.
