# Wrapped Nexus, open silhouette variations

Four refinements of the existing Wrapped Nexus concept, requested because its outer shape felt boxed. These are concept previews, not replacements for the approved brand master.

- 01 Open Wrap: closest evolution, slimmer sides and angled terminals.
- 02 Soft Fold: softer shoulders and more rounded outer transitions.
- 03 Split Flow: shorter stems and more generous diagonal seams.
- 04 Tapered Nexus: swept, pointed ends and stronger directional tension.

Each retains an N, two opposing folds and one blue central connection point. Imagegen previews target portfolio blue #02A1E1; exact production colour and geometric construction will be enforced in the final chosen vector artwork.

Individual symbol PNGs and lockup PNGs are on black. logo-comparison.png shows the four alternatives beside the original logo. Existing white wordmark SVG outlines are used without editing. Conthrax is used for comparison headings, not substituted for the existing wordmark.

Method: built-in imagegen edited the supplied symbol reference. Transparent draft extraction produced rough edges, so clean opaque previews were generated instead. prompts.json preserves the initial prompts; clean-preview-prompts.json preserves the final prompt set. Discarded transparent drafts remain in the default imagegen output folder. The local comparison source links to existing branding fonts and SVGs; distribute the PNGs rather than the font-dependent source.

build-comparison.cjs uses Playwright, Chrome and sharp for native comparison layout, screenshot exports and dimension validation. The approved brand kit and existing banner assets remain in place.
