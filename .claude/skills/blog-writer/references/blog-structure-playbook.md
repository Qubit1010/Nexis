# Blog Structure Playbook — outlines, formats, length

How to shape the post once intent + keyword are set. Pairs with `seo-aeo-geo-checklist.md` (the optimization pass) and `agency/personal-brand-voice.md` (Aleem's voice). Citations resolve via `_research/sources.json`.

## Length: follow depth, not a magic number
There is **no empirically-supported "ideal word count"** in the 2026 sources [s78][s79]. Length follows intent and topic depth. Working defaults (practitioner):
- **How-to / definition:** 900-1,400 words. Answer fast, then the steps.
- **Comparison / "X vs Y":** 1,200-1,800. Lead with a verdict, then a table, then the nuance.
- **Definitive guide / pillar:** 1,800-3,000+. Covers the fan-out cluster in one place.
- **Opinion / analysis / case study:** 1,000-1,600. POV-driven, one strong argument.

Never pad to hit a count. If short of depth, add a concrete example or answer another fan-out question — never filler [voice-principles: Length discipline].

## The universal skeleton (every post)
1. **Hook** (voice-principles hook formulas — tension/contradiction/specific moment; never "In this post..."). One clear H1.
2. **Answer-first intro:** within the first 2-3 lines, a short self-contained answer to the core query (the extractable block AI engines quote) [s26][s37].
3. **Body:** H2s phrased as the questions people ask, each opening with its own short answer, then depth. Right block per section (steps/table/pros-cons/FAQ) [s37][s38].
4. **First-hand experience woven through** — real projects, numbers, decisions (E-E-A-T + the human tell) [s73][voice-principles Pillar 1].
5. **FAQ** (3-6 fan-out questions) near the end — feeds AEO + FAQPage schema [s37].
6. **Ending** (voice-principles): zoom from the specific case to the broader principle, then one clear next step. The ending must earn the hook.
7. **SEO metadata block** appended (see checklist).

## Format templates

**How-to guide** — Hook → answer-first ("Here's the short version:") → prerequisites → numbered steps (each step = imperative H3 + why) → common mistakes → FAQ → principle + next step. Blocks: numbered steps, FAQ.

**Comparison ("X vs Y")** — Hook → verdict up top (who should pick what) → comparison **table** (dimensions as rows) → when X wins / when Y wins → your real experience with each → FAQ → recommendation. Blocks: table, pros/cons, FAQ. (Practitioner-favored format for AI citation [s37] — labeled.)

**Definitive guide / pillar** — Hook → what this covers + who it's for → definition block → the cluster of sub-questions (each an H2 answer-first) → examples from real work → decision framework → FAQ → next step. Interlink to narrower cluster posts [s46]. Blocks: definition, table, FAQ.

**Opinion / analysis / case study** — Hook (a contrarian claim or a specific moment) → the standard take you're rejecting (fresh phrasing each time, per voice-principles Pillar 2) → your argument with evidence/experience → the condition under which you'd be wrong → extractable principle. Golden Pattern (voice-principles): real problem → wrong approach → discovery → mistake → insight → principle. Never use those as literal headings.

## Marrying SEO structure with Aleem's voice (the tension, resolved)
`voice-principles.md` forbids "generic SEO filler" but **explicitly allows SEO done WITH a strong POV and real experience** (Content Ladder, level 7+). So:
- The **answer-first blocks, headings-as-questions, tables, FAQ, schema** are structure — they don't dilute voice.
- The **prose inside** must stay level 7+: lived experience, strong POV, specificity, the So-What test. An SEO blog in Aleem's voice is a POV-driven essay/case-study/guide that also happens to be cleanly extractable — not a neutral explainer with keywords sprinkled in.
- If a section reads like it could sit on any agency blog, it fails voice-principles — rewrite with a specific anchor (project type, number, real decision).

## Content type → default blocks (quick map)
| Intent | Format | Must-have blocks |
|---|---|---|
| "how to X" | How-to | numbered steps, FAQ |
| "X vs Y" / "best X" | Comparison / listicle | table, pros/cons, FAQ |
| "what is X" / broad topic | Definitive guide | definition, cluster H2s, FAQ |
| "should I / is X worth it" | Opinion / analysis | POV argument, decision criteria |
| "we did X, here's what happened" | Case study | Golden Pattern arc, real numbers |
