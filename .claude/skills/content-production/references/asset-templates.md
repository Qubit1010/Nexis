# Asset templates — skeletons for the formats nothing else owns

Fill-in skeletons only. **Why a format is shaped this way, how long it runs, what the opening
has to do and what the 2026 optimization is all live in
`content-advisor/references/format-specs/`** — read that first, then use the skeleton here to
draft against. This file deliberately carries no rationale and no numbers, so there is one
source of truth for both.

No skeleton here for anything `blog-writer`, `carousel`, `linkedin-infographics`,
`shorts-creator`, `reel-creator` or `copy-conversion` already produces.

Every skeleton assumes Phase 6 of `method.md` is done: the one action, the reader's state, the
one belief, the proof, the frame.

---

## Whitepaper

```
Title                        the finding, not the topic
Executive summary            the conclusion, standalone, readable on its own
The problem                  framed in the reader's terms, with the cost of it
What is currently done        and specifically where it breaks
The evidence                 the section the whole document exists to carry
What follows from it         the argument, step by step
Limitations                  what this does not establish. Non-negotiable
What to do                   concrete, ordered
Method / sources             how anything measured was measured
```

Cut the executive summary last. If it cannot stand alone, the argument is not finished.

## Ebook

```
Cover promise                one specific outcome
Who this is for / not for    the exclusion earns trust
Chapter per sub-problem      each ending in something the reader can do
Worked example               one, carried all the way through
Checklist or template        the part that gets kept
Next step                    one
```

## Gated guide / lead magnet

```
Promise                      what they can do after reading, stated as a capability
The shortest path            steps, in order
The part that gets saved     template, checklist, script, calculator
One worked example
Next step                    one, and only if it is genuinely next
```

The exchange has to be worth the email address. If the substance is thin, say so rather than
gating it — a download that disappoints costs more than the address is worth.

## Email newsletter (standalone issue)

```
Subject line                 3 options
Preview text                 extends the subject, never repeats it
Opening                      one idea, immediately
Body                         single-topic or roundup, per the spec
The takeaway                 what the reader now knows or can do
One CTA
Sign-off
```

## Customer case study (the client's customer, not a NexusPoint project)

```
Headline                     the result, specific
The customer                 who, and why they are recognisable to the reader
The situation before         with the cost of it, in their words where possible
What was tried               including what did not work
What was done
The result                   with the measurement method, and the timeframe
What made it work            the transferable part
Quote                        real, attributed, approved. Never invented
```

If the customer will not disclose numbers, say what changed qualitatively and label it. A case
study with an invented figure is worse than one with none.

## Thread (X or LinkedIn)

```
Post 1     the whole claim, standalone. It has to work if nothing else is read
Post 2     why it matters / the cost of the status quo
3..n-1     one idea each, concrete, no post that only sets up the next
Post n     the resolution, then one action
```

A thread that requires post 1 to be read as a teaser is a thread that dies at post 1.

## Single text post

```
Line 1       before the truncation point, carries the whole point
Body         one idea, in the format's own shape per the spec
Close        one action, or a genuine question
```

## Meme

```
Format             the specific template, named
The tension        the in-group observation it lands on
Brand fit          why this brand has the licence to say it
```

If the brand fit line is hard to write, the answer is that they should not post it. That is a
legitimate output of this skeleton.

## Short-video script (TikTok / vertical)

```
0-3s      the hook, spoken and on-screen
Setup     the stake, one line
Body      beats, one idea each
Payoff
Loop or CTA
On-screen text     per beat, written out
```

## Long-form video script (YouTube)

```
Cold open           the payoff or the tension, before any branding
Promise             what they will be able to do by the end
Chapters            each a self-contained unit with its own small payoff
Retention beats     where the pattern changes, marked
Payoff
End screen action   one
Title + thumbnail   3 options each, written together
Description         first two lines carry the search-visible summary
```

## Webinar

```
Pre-frame           what they will leave with, stated in the first 2 minutes
Agenda              3 blocks maximum
Blocks              each with an interaction point
The drop-off point  what happens at the moment attention usually goes
Q&A                 seeded with 3 real questions
Offer               if there is one, once, at the end
Follow-up           what the recording gets repurposed into
```

## LinkedIn document carousel

```
Cover      the claim, legible at feed size
Frames     one idea per frame, no frame that only sets up the next
Recap      the whole argument on one frame, for the saver
CTA        one
```

Text per frame stays at what is readable on a phone, per the spec.

## Podcast show notes

```
Episode title
One-paragraph summary
Timestamps           real, from the transcript. Never estimated
Key points           3-5, each standalone
Links and references
Guest bio            if there is one
```
