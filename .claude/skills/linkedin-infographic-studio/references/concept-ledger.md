# Concept ledger

The memory that keeps the infographics different from each other. The pattern is borrowed from
`hyperframes-reel` and `blog-images`, the two places in this repo where a ledger has actually kept
a long batch visually distinct.

**Before proposing concepts:** read the last ten rows. None of the three concepts you offer may
reuse a visual world from those rows. A different colour on the same world is the same world.

**After emitting a prompt:** append one row. Do this even if Aleem never renders it, because a
concept he saw and declined is still one he has seen.

**The test:** cover the text on two entries. If the drawings would still read as the same
picture, one of them is wrong.
