# Signature ledger

The one rule that makes every article's artwork feel bespoke: **each article's cover carries its own
diagram archetype, and no two articles repeat it.**

The genome is constant: dark ground, the palette, Urbanist, one accent subject, flat orthographic
drawing. The *signature* is the **kind of object** the cover is built from, and it must be
structurally distinct from everything already shipped.

Borrowed wholesale from `hyperframes-reel/references/signature-ledger.md`, which is the only
mechanism in this repo that has actually kept a batch visually distinct over a dozen artefacts.

**Before authoring a cover:** read this ledger. Pick an archetype that is a different *kind of
object* from every row below, not a restyle of one. A ladder, a track, a dial, a split panel, a
stack and a branching tree are six different worlds. Two hub-and-spoke graphs are one world.

**After shipping:** append a row. This file is the memory that keeps the batch diverse.

## The test

Cover the labels. If two covers still read as the same drawing, one of them is wrong.

## Built so far

| Slug | Cover archetype | World / device | Accent subject |
|---|---|---|---|
| `ai-agent-vs-skill` | split panel: one bounded task versus a 5-step chain where the error propagates forward | **two facing panels** (a comparison frame) | the propagating chain in the agent panel |
| `how-to-outsource-web-development` | a three-layer cost stack where only the top layer is ever quoted | **a stack seen from the side** (a layered mass) | the two unquoted layers below the waterline |
| `ai-automation-cost` | a vertical price ladder, bands by scope, with the three variables as rungs | **a ladder / measured scale** (a calibrated axis) | the band the reader is actually buying |
| `ai-agent-evaluation-framework` | a horizontal score bar with a noise floor marked at 50%, and the reading that means nothing | **a gauge with a dead zone** (an instrument reading) | the noise floor itself |
| `best-n8n-projects` | a five-station pipeline, each station carrying the specific thing that broke | **a conveyor line with stations** (a process track) | the break marker at each station |
| `ai-agent-vs-automation` | a fixed rail beside a branching tree, same start, different auditability | **a rail versus a branching tree** (two path topologies) | the branch points on the tree |
| `codex-vs-claude-code` | a balance scale sitting level between the two tools' SWE-bench scores, because a tied instrument has stopped being a reason to pick either one | **a balance / lever** (a weighing instrument) | the level beam itself, the reading that means nothing |

## Worlds already used, do not reach for these again

two facing panels · a side-on stack · a calibrated ladder · a gauge with a dead zone ·
a station pipeline · a rail versus a tree · a balance / lever

## Worlds still open

a nested containment (rings/boxes inside boxes) · a map with a boundary ·
a timeline with a break · a grid that fills · a funnel · a switchboard · a ledger/table that
reconciles · a container that leaks · a lens or filter stack

Note: `codex-vs-claude-code` also used a funnel (3 tests converging) and a leaking container
(cost mismatch) as **supporting figures**, not covers. Both stay open for a future cover -
this ledger only tracks the cover archetype.
