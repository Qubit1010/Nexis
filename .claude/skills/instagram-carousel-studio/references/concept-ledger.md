# Concept ledger

Every carousel concept shipped, so the sets stay different from each other. Same pattern as the
infographic skill's ledger, borrowed from `hyperframes-reel` and `blog-images`.

**Before proposing concepts:** read the last ten rows here, **and** any row in
`../linkedin-infographic-studio/references/concept-ledger.md` for the same post. Aleem decided
on 2026-09-25 that a post's Instagram carousel and LinkedIn infographic use different worlds,
so a world used for this post on LinkedIn is off limits here.

**After emitting the prompts:** append one row, even if the set is never rendered.

## Off limits from day one

The worlds `carousel` already produces from its six templates. A concept that resembles one of
them has failed at the only thing that makes this skill different.
