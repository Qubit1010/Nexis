## Connects economics — treat it as an ad budget

| Item | Figure | Q |
|---|---|---|
| One connect | **$0.15** | Q4 |
| Standard proposal | **6-16 connects ($0.90-$2.40)** | Q4 |
| Boost | **+10-60 connects** | Q4 |
| Boost worth it above | **$1,000 job value**, with directly relevant proof | Q4 |
| Freelancer Plus worth it above | **8 proposals/month** | Q4 |

**Boost mechanics:** buys a top-4 slot; you pay **only** if you land top-4 or the client interacts.
Outbid before engagement = connects refunded [Q4].

**The rule that governs all of it:** if win rate is low, boosting and volume *accelerate losses*.
Fix targeting before spending more [Q4].

## Ranking signals (search visibility)

Weight order per the sources [Q2]:

1. **Relevance / niche density** — algorithm favors specialists over generalists
2. **JSS + private feedback** — **90%+ JSS critical** for placement; private feedback weighted heavily
3. **Profile completeness** — 100%, photo, **6+ portfolio items**, verified skills (baseline, not bonus)
4. **Activity + responsiveness** — daily login, current availability, reply **within a few hours**
5. **Skill tags** — **exactly 15**, niche-relevant. Irrelevant tags cause **de-ranking**

**2026 structural change:** discovery is increasingly *push*. An AI agent ("Uma Recruiter") builds
shortlists and issues invites, so **invite-to-hire ratio is now a signal**. Decline poor-fit invites
immediately with an explanation — it trains the matcher [Q2].
