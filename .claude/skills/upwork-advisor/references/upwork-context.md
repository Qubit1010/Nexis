# Upwork Context

The **one** file holding personal context, so the rest of the skill stays generic and publishable.
Read it before any advice that depends on current standing (badge distance, rate raises, portfolio
mix, whether a job is above or below his floor).

If you publish this skill, replace the "Active profile" block with the "Generic default" and strip
nothing else. No personal identity should appear anywhere but here.

---

## Generic default (use when no profile is set)

- **Who:** an established freelancer with a track record, not a beginner.
- **Positioning:** a specialist in a specific stack or outcome, not a generalist.
- **Goal:** better clients at higher rates, and fewer, better-targeted bids.
- **Constraint:** time. Bidding volume is capped by attention, not connects.
- **Standing:** unknown — ask before giving badge-, rate-, or JSS-threshold-specific advice.

When on the generic default, **ask one calibrating question** before advice that depends on current
standing.
